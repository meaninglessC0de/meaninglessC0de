
Hi! I'm Anish, a second year Computer Science student at Imperial College London. 

> My username originates from [_Ending C_](#) of Nier Automata.

Here are a few cool/useful repositories that I've work on:

- [AudioFx](#) - A real-time, embedded digital signal processor that runs locally on a Raspberry Pi. The various audio effects include distortion, tremolo, chorus, and reverb. Written in pure C!
- [ClearSky](#) - This was a project I helped build for IC-Hack 2026. We were inspired by research that demonstrates how contrails are responsible for ~80% of the aviation industry's warming effects, and the aim is to create a flight-routing system that avoids contrails by navigating away from high condensation regions.
- [Jake's Resume Cover Letter](#) - (perhaps the most useful one to you) This is a cover letter to accompany the standard Jake's Resume.
- [EpsilonDelta](#) - This is a mathematics learning platform aimed at college students. My favourite featured here are the 3blue1brown style video generator and the real-time whiteboard checker. The project won 1st Place at HackLondon 2026.
- [RTGS Payment Simulator](#) - A CLI that lets you simulate interbank transactions within Real-Time Gross Settlement systems. We include various resolvers to solve gridlocks in queued payments.
- [Word2Vec](#) - An implementation of skip-gram word2vec with negative sampling.
